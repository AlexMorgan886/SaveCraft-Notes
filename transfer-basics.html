TRANSFER CHECKLIST

Moving game saves between installations or devices

Save transfers are usually straightforward when the source, destination, and file structure are compatible. The important part is checking those conditions before replacing anything.

Start with a backup

Before transferring anything, make a copy of the working save. Store it somewhere outside the destination folder.

This gives you an untouched version if the destination installation does not recognize the copied files.

Check the game version

Save compatibility can depend on the version of the game. A save created by one version may behave differently after a major update or when used with a significantly different build.

If you are transferring a save for Summertime Saga, it is useful to check a dedicated save-file transfer guide for the game's specific considerations rather than assuming that every installation uses the same process.

Copy the relevant files

Avoid copying an entire installation simply because you cannot determine which files contain the progress. Identify the actual save data first.

Keeping save data separate from application files makes future backups and transfers much easier.

Do not immediately delete the source

Test the transferred save before removing the original. Launch the destination installation and confirm that the expected progress is available.

Important: If the transferred save does not appear, stop and restore from the backup instead of repeatedly changing files at random.

After the transfer

  1. Launch the destination installation.
  2. Check that the save appears.
  3. Load the save.
  4. Confirm important progress is present.
  5. Make a fresh backup of the working result.

Avoid unnecessary complexity

Most save-transfer problems become harder to diagnose when several variables are changed simultaneously. Transfer one known-good backup, test it, and only then investigate additional compatibility issues.
