BACKUP BASICS

How to back up game saves before making changes

A proper backup gives you a way back when an update, reinstall, transfer, or file experiment goes wrong.

1. Find the actual save files

Start by identifying where the game stores its saves. The location can differ by operating system, installation method, game engine, and sometimes even game version.

Do not assume that the folder containing the game's executable is also the folder containing its progress.

2. Close the game first

Always close the game before copying save files. If the application is still running, it may be writing data while you are creating the backup.

3. Copy instead of moving

For the first backup, copy the save folder or relevant files to a separate location. Do not move the originals.

Good practice: Keep the original files untouched until you have confirmed that the backup opens correctly.

4. Give backups useful names

A folder named backup-final-final2 becomes difficult to understand after a few months. Use names that tell you what the backup represents.

  • GameName-before-update
  • GameName-before-transfer
  • GameName-working-save-2026-09

5. Keep more than one generation

If a save is important, maintaining two or three separate backup points is safer than repeatedly overwriting the same copy.

A useful pattern is to keep one recent backup and at least one older copy that has not been overwritten.

When should you make a backup?

Before an updateProtect progress before changing the installed version.
Before reinstallingKeep progress separate from the installation process.
Before transferring devicesPreserve the original before attempting the copy.
Before troubleshootingCreate a recovery point before modifying files.

Final check

A backup is only useful if you know where it is and can identify which version of your progress it contains. Keep the original and backup clearly separated, and avoid editing both at the same time.
